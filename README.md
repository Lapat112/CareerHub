**** History ****
    ระบบทำงานโดยการดึงข้อมูลที่ผูกกับผู้ใช้งานผ่านทาง Local storage โดยการส่ง UUID ของคนนั้นมา
    
    **ปัญหาที่เจอและวิธีการแก้ไข**
        ปัญหาที่เจอคือ ตอนทำโปรเจ็คช่วงแรกข้อมูลที่เก็บเป็น int แต่พอเริ่มที่จะทำให้ระบบปลอดภัยมากขึ้นจึงจะเปลี่ยนจากการเก็บข้อมูลจาก int เป็น UUID แทน
                   *** ปัญหาที่เกิดเมื่อเปลี่ยนเป็น UUID  ***
                        -เมื่อจะเปลี่ยนชนิดข้อมูลจาก int เป็น uuid สิ่งที่เกิดขึ้นคือไม่สามารถเปลี่ยนได้เพราะข้อมูลที่เก็บอยู่แล้วเป็น int จึงทำให้ไม่สามารถเปลี่ยนเป็น uuid ได้
                          (การแก้ปัญหาคือ  สร้าง Columns มาอีกอันที่เก็บเป็น uuid และแก้ข้อมูลทีละคนเนื่องจากผู้ใช้ยังน้อย
                            ***หากผู้ใช้มีเยอะแก้ยังไง***
                               -สั่ง AI ให้ช่วยแก้ข้อมูลโดยมี Dev คอยคุมการทำงานอย่างใกล้ชิด
                               -ออกแบบการเก็บข้อมูลไว้แต่แรก
                          )
